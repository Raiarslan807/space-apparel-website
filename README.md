# Space Apparel — React Website

A responsive, multi-page website for Space Apparel, a custom apparel and streetwear manufacturer based in Sialkot, Pakistan.

## Features
- React + Vite + React Router
- Home, About, and Contact pages
- Responsive navigation with mobile overlay
- Service cards, process timeline, testimonials, and contact CTAs
- WhatsApp and email links
- SEO title, description, and keywords
- Scroll reveal animation and reduced-motion support

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in your terminal.

## Production build
Run `npm run build`. The production site is generated in `dist/`.

## Update before publishing
- Replace the remote Unsplash image URLs with your own factory, product, and production photos for a more authentic brand presentation.
- Confirm business details, testimonials, lead times, and any manufacturing claims before publishing.
- The testimonial copy supplied in the brief is presented as sample client feedback; only publish it as a real testimonial if verified.
- Deploy the `dist/` folder to your hosting provider, or connect this project to a Vite-compatible hosting platform.
