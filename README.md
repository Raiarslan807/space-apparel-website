# Space Apparel Website

A modern, responsive, multi-page apparel business website built with React, Vite, and React Router.

**Developed by Arsalan Ramzan**

## About the Project

Space Apparel is a real-world web development project created to establish a professional online presence for a custom apparel and streetwear business.

The project focuses on modern UI/UX, responsive design, reusable components, smooth navigation, and practical customer communication features.

## Key Achievements

- Developed a complete multi-page React website.
- Implemented client-side routing for Home, About, and Contact pages.
- Built a responsive navigation bar with a mobile menu overlay.
- Created reusable components for services, testimonials, calls to action, and process sections.
- Integrated WhatsApp and email links for direct communication.
- Implemented scroll-to-top behavior and scroll reveal animations.
- Added SEO metadata and reduced-motion accessibility support.
- Structured the application for maintainability and production builds.
- Configured the project for Git and GitHub version control.

## Run Locally

### Prerequisites

Install Node.js (LTS) and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/Raiarslan807/space-apparel-website.git
```

Navigate to the project directory:

```bash
cd space-apparel-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Production Build

Build the application:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

The optimized production files are generated in the `dist/` directory.
